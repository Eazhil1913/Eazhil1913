## Cybersecurity Learning

My security learning is practice-oriented and takes place in ethical, authorized environments. Current areas of study include:

- Linux and Kali Linux fundamentals
- Networking concepts, including TCP/IP, DNS, and ports
- Network reconnaissance with Nmap in authorized labs
- Web application security concepts and the OWASP Top 10
- SQL injection fundamentals and secure coding awareness
- Request inspection and traffic analysis with Burp Suite
- Authentication and authorization concepts
- Ethical hacking labs and CTF exercises
